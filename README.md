# 🌠 Meteor Client

A custom Minecraft client project inspired by the Meteor Client experience.

> ⚠️ **Work in Progress**
> This project is currently being developed. Features, modules and the design may change over time.

## 🚀 Features

* 🖥️ Custom Minecraft client interface
* ⚙️ Modular feature system
* 🎨 Custom GUI and HUD
* 📊 In-game information displays
* 🔧 Customisable settings
* 🧩 Support for additional modules
* 🚧 More features coming soon

## 📦 Installation

### Requirements

* Minecraft
* Java
* The required Minecraft version for the current release

### Setup

1. Download the latest release.
2. Install the required dependencies.
3. Place the client/mod into your Minecraft installation.
4. Start Minecraft.
5. Configure the client in-game.
